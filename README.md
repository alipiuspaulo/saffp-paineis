# SAFF-P · Painéis ANTT

Painéis com dados ao vivo das camadas do ArcGIS Online, na identidade visual da ANTT,
incorporados no ArcGIS Experience Builder (Demo - SUFER / SAFF-P).

- `pit/` — Projeto de Interesse de Terceiros (PIT)
- `fico/` — Fiscalização FICO (com galeria de fotos)
- `acidentes/` — Acidentes Ferroviários
- `logo/` — cartão animado do logo SAFF-P / SUFER / ANTT
- `assets/` — motor comum (painel.js / painel.css)
